# 💫 About Me:
Nisarg Modi is a Senior DevOps and Platform Engineer based in Riyadh, Saudi Arabia, with over 15 years of experience across banking, healthcare, and enterprise environments. He specializes in cloud infrastructure, release automation, CI/CD, and container platforms utilizing AWS, Terraform, Kubernetes, and Ansible. Certified as a CKA and AWS Solutions Architect, Nisarg is dedicated to driving operational efficiency, maintaining strict security compliance, and delivering scalable, reliable cloud solutions.<br>
